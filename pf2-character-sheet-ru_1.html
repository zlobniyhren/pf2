Чтение работает без токена, если репозиторий публичный. Для записи нужен fine-grained токен на этот репозиторий с правом Contents: Read and write (github.com/settings/personal-access-tokens). Токен хранится только в этом браузере. Персонажи объединяются по времени последнего изменения: где правили позже — та версия и побеждает. Удаление персонажа на другом устройстве не переносится.
